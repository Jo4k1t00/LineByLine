## ¿Qué es?

Un proyecto en Unity 6 para aprender programación de gameplay. Cada mecánica
tiene una terminal al lado con su código real, resaltado a color el estilo
Visual Studio, y un botón **?** con una explicación paso a paso pensada para
principiantes.

## Caracteristicas

1. Resaltado de lineas durante ejecucion
2. Explicacion Manual con los fragmentos deztacados del codigos con respectiva definicion.
3. Sistema Reutilizable: crear una demo nueva = una clase + un .txt


## Herramientas Usadas
- C#
- Unity 6.3 LTS
- Github
